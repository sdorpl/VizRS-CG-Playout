Godzinę emisji ustawiasz w harmonogramie kanału w ErsatzTV: pozycja z kolekcją „LIVE · …”, start stały, tryb One. Resztę robi panel.

Połączenie z ErsatzTV

biblioteka Remote Streams z folderem /config/vizrs-live

ID biblioteki podajesz raz – ErsatzTV nie udostępnia listy bibliotek przez API (widać je w adresie strony biblioteki: /media/libraries/…/7).

Przebuduj ramówkę

Po zmianie harmonogramu w ErsatzTV przebuduj playout kanału, żeby audycje trafiły do EPG.

Nowa audycja LIVE
widoczny w EPG i jako {title} w grafice VizRS
w czasie audycji bez sygnału studia kanał pokazuje czerń z ciszą

    1. Start Type: Fixed, godzina emisji, Fixed Start Time Behavior: Strict
    2. Collection Type: Smart Collection →
    3. Playout Mode: One
    4. opcjonalnie Graphics Elements: VizRS
    5. Save Schedule Items, potem wróć tu i kliknij „Przebuduj ramówkę”
    Panel sprawdza w EPG, czy audycja jest w ramówce, i pokazuje najbliższą emisję.
